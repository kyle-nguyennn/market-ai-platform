# Generated research outputs

Output files in this folder are generated by `python -m competitions.alphanova.research.run_experiments`.

`summary.csv` contains official-style aggregate gross/net Sharpe and a separate de-overlapped history diagnostic; `per_period.csv` contains period-level metrics; `manifest.json` records experiment settings and dataset period keys.

Do not check in large experiment artifacts or training datasets; use separate subdirectories per experiment to avoid overwrites.
